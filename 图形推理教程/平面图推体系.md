# 平面图推：一个体系（草案）

## 核心一句话

**每道平面题 = 从每幅图里取出一个值，这串值满足一个简单规律。**

出题人按四步出题：
1. 选一个规律；
2. 选一种取值方式；
3. 画图：把要取的那串值锁死，其余的一切故意打乱；
4. 出选项：只有一个选项的值符合规律。

解题，就是把这四步倒推回去。

## 总图

```
平面图推
│
├─ ① 格式        → 规律是什么形状
│    一行 5~6 幅    → 数列：恒定 / 递变
│    3+3 两组       → 第一组示范，第二组照做：任意三项模式
│    九宫格         → 每行（或每列）：恒定 / 运算 c=f(a,b) / 遍历
│    六图分两类     → 二值性质：是 / 不是
│
├─ ② 在哪里取值   → 图与图之间有没有相同的部件？
│    有 → 图间取值：比较相邻两幅，看变了什么
│    无 → 图内取值：每幅图单独测一个量
│
├─ ③ 对谁取值
│    整幅图 / 拆开的各部分（黑白、内外、大小）/ 标记指着的局部
│    两部分之间 / 某部分与背景或外框
│
├─ ④ 取什么值
│    图间：移动（平移、旋转、翻转；只动一部分 = 相邻比较）
│          组合（叠加、求同、求异、黑白运算）
│          分配（遍历）
│    图内：性质（对称、曲直、开闭）
│          连接（部分数、面、笔画、交点）
│          形状（直线/曲线、直角、平行、边数）
│          组成（元素的种类、个数）
│          关系 = 两个对象各取一个值再比较，或者取它们的交集
│
└─ ⑤ 验证         → 这串值简单，而且恰好一个选项符合
     排序依据      → 惊讶度 × 先验
```

五步各回答一个问题：规律长什么样？在哪里取值？对谁取值？取什么值？取对了吗？

---

## ① 格式：规律是什么形状

**为什么格式会透露规律？** 出题人给的图就是全部数据。这些数据必须够用：既要能把规律唯一地确定下来，还要多出一部分用来验证。所以格式一定，规律能有多复杂也就定了。

| 格式 | 数据怎么用 | 规律能长成什么样 |
|---|---|---|
| 一行 5~6 幅 | 所有图共用一个规律 | 恒定（最常见），或简单递变（+1，+2…） |
| 3+3 两组 | 第一组教你，第二组验证 | 任意三项模式：+1、0、−1；平行、斜交、垂直 |
| 九宫格 | 前两行教你，第三行验证 | 行内运算 c = f(a, b)，行内恒定，或每行把同一套元素各用一次（遍历）。按行读不通，就按列读，或按 S 形读成 8 项数列 |
| 六图分两类 | 两类各 3 幅，互相印证 | 一个是/不是的性质，或两种不同的值 |

**要点：每组有 3 幅图（3+3、九宫格的行）时，才可能出现“两幅图算出第三幅”的运算。** 一行 5 幅的格式很少出运算。

## ② 在哪里取值：图间，还是图内

这一刀把所有题目分成两半，而且看一眼就能判断。

**为什么这一刀在最前面？** 形状的自由度几乎无限。几幅图里出现一模一样的部件，这不可能是随手画出来的，说明这几幅图是从同一批部件变出来的。

- **有相同部件 → 图间取值。** 规律就在“相邻两幅之间变了什么”。取出来的值是变化的参数：移了几格、转了几度。
- **没有相同部件 → 图内取值。** 每幅图各画各的，能把它们联系起来的只有某个抽象的量。取出来的值是每幅图的测量结果。

两条路最后都变成一串值，所以最后一步其实都是在找数列规律。

**两个例外，都有相同部件，但不是在“变”：**
- **标记**：每幅图都有一个相同的小记号（小黑点、小箭头）。它本身不动，作用是指一个地方给你看。这类题转到③，对“标记指着的局部”取值。
- **遍历**：相同的元素反复出现，但没有移动，也没有叠加，只是被重新分配到各个格子里。这类题归到④的“分配”。

---

## ③ 对谁取值

**为什么要单独问这一步？** 出题人在每幅图里画几个对象、怎么区分它们，本身也是一种选择。如果每幅图都**稳定地**有两个部分，还用颜色、内外、大小把它们区分开，那么这个结构就是被锁死的。而锁死它的唯一理由是：**规律需要这几个输入。**

| 对象 | 什么时候选它 |
|---|---|
| 整幅图 | 默认。图是一个连在一起的整体，没有被标记区分开 |
| 拆开的各部分 | 每幅图都稳定地分成两类（黑/白、内/外、大/小）。先分开测，再求关系 |
| 标记指着的局部 | 每幅图都有同一个小记号。测它指着的那个角、那条线、那个面、那个点 |
| 两部分之间 | 每幅图固定两个对象，但各自的数量都是小常数，数不出变化 |
| 某部分与背景或外框 | 背景乱到数不清，但每幅图都有同一个图形 |

这一步对图间取值同样有效：
- 16 宫格里“里圈和外圈分开走”，就是先拆成两部分，再各自看移动；
- “拆分后做加减同异”，就是先拆开，再各自做组合。

## ④ 取什么值

### 图间：部件之间有三种变化方式

| 方式 | 内容 | 怎么看 |
|---|---|---|
| **移动** | 平移（步长、方向、到边缘后从另一头回来）、旋转（角度、方向）、翻转；只动一部分就是相邻比较 | 追踪同一个部件，把相邻两幅的位置作比较，得到“步长数列”或“角度数列” |
| **组合** | 两幅叠成第三幅：相加、相减、求同、求异；按黑白格为单位叠加，就是黑白运算 | 把线或格子看成开关。同样的一对输入，必须得到同样的输出（找相同区域）。要先对齐，确认哪幅图被转过 |
| **分配** | 同一套元素，在每一行（或每一组）里各出现一次 | 缺哪个补哪个 |

### 图内：可以测的量只有四族

**为什么只有这四族？** 一幅图里的信息只有：由哪些部分组成、怎么连接、每条线什么形状、整体有什么性质。

能被拿来考的量还要过三道筛子：
- 眼睛能看准；
- 放大、缩小、旋转都不会变；
- 出题人能单独调整它。

能过筛的就是下面四族：

| 族 | 量 | 说明 |
|---|---|---|
| **性质** | 对称（类型 → 轴数 → 轴方向 → 轴与线/面/点的关系）、曲直、开闭 | 看一眼就能判断的整体性质 |
| **连接** | 部分数、面数、笔画数、交点数、端点数 | 拓扑量，画歪了也不变。笔画数 = 奇点数 ÷ 2 |
| **形状** | 直线数、曲线数、直角、平行、边数、角的类型 | 几何量，只取特殊值：0°、90°、直或曲、长短顺序 |
| **组成** | 元素种类、每种个数、换算、有没有相同元素 | 一幅图由几个分开的小图形组成时使用 |

### 关系：把两个对象组合起来取值

两个对象之间的值，只有两种取法：

| 取法 | 例子 |
|---|---|
| **各取一个值，再比较** | 两条对称轴平行、斜交还是垂直；黑框和白框的边数差；两个图形的接触边是不是各自的最长边 |
| **取它们的交集** | 碰没碰、包不包含；交在点、线还是面；重叠出来的形状有几条边；与外框接触了没有 |

所以“图形关系”不是一族新的量，而是四族量用在两个对象上的结果。

## ⑤ 验证与排序

**验证。** 取出的这串值要满足两个条件：
1. 很简单：恒定、等差，或第二组照抄第一组的模式；
2. 选项中**恰好一个**符合。

两个选项都符合，说明取值还不够细，要往下一层看。一个都不符合，说明假设错了，换一个。

**排序：惊讶度 × 先验。**
- **惊讶度**：这个规律在“随手画”的情况下出现的可能性越小，越可能是出题人锁死的。
  - 只看出题人**本可以随便画**的维度。两个三角形的面数本来就小，它恒定不算惊讶。
  - 一个特征在各幅图之间乱变，说明它是被打乱的部分，直接排除。
- **先验**：出题人常考什么。广东常考位置（含纵向）、加减同异、图形关系、数量；开闭性、拆分式加减同异很少出现。

**由此自然得出的扫描顺序：**
1. 看格式、看有没有相同部件、数对象个数：一眼就能判断，而且信息量最大，放在最前面。
2. 图内取值时，先查看一眼就能判断的：整体对称，以及有两个对象时的关系。
3. 再数惊讶度最高的那个量：刻意的直角、刻意的平行、多出来的小线段、每幅图都同时出现曲线和直线。
4. 找不到明显信号时，按面 → 笔画 → 点的顺序硬试。这是按“数起来的成本”从低到高排的。

## 卡住时往回退一步

| 卡住的现象 | 退回到哪一步 |
|---|---|
| 数列怎么都不简单 | ④ 换下一个惊讶度高的量 |
| 所有量都没规律 | ③ 换对象：整图 → 拆开 → 关系 → 与背景 |
| 移动、组合都说不通 | ② 换取值方式：图间 ↔ 图内 |
| 九宫格按行不行 | ① 换读法：按列、按 S 形、分两组 |

## 覆盖检查：老师的每个考点落在哪里

| 老师的考点 | 在本体系中的位置 |
|---|---|
| 平移、旋转、翻转 | ② 图间 ④ 移动 |
| 相邻比较 | ② 图间 ④ 移动（只动一部分） |
| 宫格内外分开看、隐藏外框 | ③ 拆开 + ④ 移动 |
| 加减同异（含纵向） | ① 3+3/九宫格 ② 图间 ④ 组合 |
| 加减同异拆分 | ③ 拆开 + ④ 组合 |
| 黑白运算、谁动 | ④ 组合（以黑白格为单位；先对齐） |
| 遍历 | ① 九宫格 ④ 分配 |
| 标记（点、线、角、面） | ③ 标记指着的局部 + ④ 图内任一量 |
| 对称：类型、轴数、方向、与线面点、+笔画 | ④ 性质（轴与线面点 = 性质 × 连接） |
| 对称 1+1（轴的关系）/ N+N（识别） | ③ 拆开 + ④ 关系（比较） / ④ 性质 |
| 曲直、开闭 | ④ 性质 |
| 面、部分数、笔画、交点、切点、曲直交点 | ④ 连接 |
| 面的细化（形状、最大面、相同面） | ③ 局部（某个面）+ ④ 形状/性质 |
| 线数、横竖线、平行、直角 | ④ 形状 |
| 曲线与直线、黑框与白框、大框与小框运算 | ③ 拆开 + ④ 形状 + 关系（比较） |
| 元素种类、个数、换算 | ④ 组成 |
| 元素找相同（自己、邻居） | ④ 组成；和邻居比较时属于 ② 图间 |
| 相离距离、包含层数、相交于点/线/面 | ③ 两部分之间 + ④ 关系（交集） |
| 复杂型（共同图形）、看得见/看不见的外框 | ③ 与背景或外框 + ④ 关系（交集） |
