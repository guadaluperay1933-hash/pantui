# 图形推理速成教程

> 由义恒老师《判断推理·图形推理》9 节直播课整理：课件截图配图，讲稿去掉水分后凝练成文字，每个规律都讲清“看到什么 → 想到什么 → 怎么做 → 哪里有坑”。
> 带 **💡 解释** 或“补充”字样的段落是整理时加的原理说明，不是老师原话，结论与老师一致。

## 怎么用这份教程

1. **先花 10 分钟看下面的“一页总纲”**，脑子里先有一张地图。
2. **按顺序学第 1～5 章（平面）**。每章开头的“本章要点速览”是整章的压缩版，最后的“本章小结”有速查表、口诀和易错坑汇总，复习时只看这两块就够。
3. **学完平面后读第 6 章**。它把平面图推串成一棵决策树，还讲了强弱特征、六大混淆点，并完整讲了**图形关系**和**遍历**两个前面没讲的考点。
4. **再学第 7～9 章（空间）**。
5. 刷题时把错题标在第 6 章的思维导图分支上。同一分支错得多，就回到对应章节重看，再专项练 10 题左右（老师的复盘方法）。

每道例题都按“**思路**（考场上的思考顺序）→ **答案**”写。建议先遮住思路自己做，再对照。

离线或手机阅读可以用合订本 **[图形推理教程.pdf](图形推理教程.pdf)**。

## 一页总纲：拿到一道图推怎么想

### 第 0 步：看出题形式

| 形式 | 怎么看 | 出题人喜好 |
|---|---|---|
| 一组图 | 从左往右 | 恒定、等差、周期（交替） |
| 两组图 | 左边找规律，右边用规律 | **等差、恒定**优先，运算很少 |
| 九宫格 | 第一行找、第二行验、第三行用 | 横向约 95%，纵向约 5%（难题）；可考运算（面、元素好数） |
| 分组分类 | 六个图平均分两类 | 两种规律；一般**不考位置和运算** |
| 空间类 | 给立体图或展开图 | 见下面“空间” |

### 第 1 步（平面）：有没有“一样的图案”？——“3+3”框架

```
有一样的图案
├─ 完全一样（元素相同，只是位置、方向变）──→ 位置规律【第1章】
│    ├─ 宫格（9/16/25 宫格、蜂窝）：先看内部 → 内部有规律就内外分开看，否则常规平移
│    ├─ 只有线段、没有宫格 → 隐藏外框：找特殊线、就近
│    ├─ 整体换朝向 → 旋转/翻转：箭头法、时针法
│    └─ 大部分不动、局部在变 → 相邻比较（颜色互换 / 移动）
└─ 部分一样
     ├─ 相同位置的线条 → 加减同异【第2章】：看图3反推；谁动、纵向、拆分
     ├─ 外轮廓一样，内部黑块个数不同 → 黑白运算【第2章】：相同区域、对比选项
     ├─ 几样元素轮流出现 → 遍历（选修）【第6章】：缺啥补啥
     └─ 每幅图都有同样的小元素、背景不同 → 标记【第2章】：标什么考什么

没有一样的图案
├─ 属性【第3章】
│    ├─ 规则、美观 → 对称性（大哥）：先识别，后细化；只有“全是一条轴”才多想，其余快速排
│    ├─ 曲线占 1/2 或 2/3 → 曲直性（直接定位）
│    └─ 生活化图形 → 开闭性 / 面 / 部分数 / 笔画
├─ 对称不行，图形过于简单（两个图案）或过于复杂 → 图形关系【第6章】
│    相离（距离）、包含、相交（点：首尾/中间；线：数量、长短；面：形状、属性）；复杂型；与外框的关系
└─ 正常情况 → 数量【第3～5章】
     ├─ 强特征直接定位：
     │    五角星、日、田、圆相交 → 笔画｜直角三角形、十字架、矩形 → 直角｜独立小图 → 元素
     │    单一线条、都有曲线、两个多边形 → 线的运算｜斜线、相似三角形 → 平行线
     │    明显大/小面、处处三角形、一样的面 → 面的细化
     ├─ 全部图都有曲线 → 曲线思路：一个圆 → 切点 → 框点；两圆相交 → 笔画 → 点；非圆 → 曲直交点 → 曲线直线运算
     └─ 只有弱特征：只有面特征 → 面 → 笔画 → 点；多端点 → 笔画 → 点
```

## 最该背的口诀

> - 每题问两句：**怎么识别考点？怎么变？** 识别是最大的难点。
> - 个数 3、3、3 或 3、3、2 → 位置；3、3、4 → 排除位置。**个数相等优先位置，个数不同优先黑白运算。**
> - **拆分思维，就近假设；双胞胎先标记，必须动；多胞胎找方向，走到头循环走。**
> - **16 宫格内外分开看，关注内部；内部都有什么就考什么。**
> - **相同位置的线条 → 加减同异；看图三反推；九成考求异。两勾图3不动，两叉图3动，一勾一叉，叉的那个动。**
> - **对称是大哥，曲线是二哥。先识别，后细化；一条看方向，多条看数量。**
> - **过于简单、过于复杂 → 图形关系；接触的地方是什么就考什么。**
> - **强特征先，弱特征后；面是最弱的特征。没有强特征就按面 → 笔画 → 点。**
> - **笔画数 = 奇点数 ÷ 2；端点也是奇点；外框不影响笔画。**
> - **6+6：所有、大小、相同 + 形状、属性、面积。**
> - **找相同：先找自己，再找邻居；两种元素先运算后换算（图1 + 图3 = 2 × 图2）。**
> - **直角少数直角，直角多数笔画；外直角白数黑不数。**
> - **外部轮廓定方向，内部线条定选项；视图可转不可翻。**
> - **截面：一刀切、刀无限大、不能拐弯；视图有线，截面没线；只有竖直过顶点才切出纯直线。**
> - **立体拼合找特殊：先代最大、最抽象的块，铅笔涂黑，看剩余轮廓。**
> - **平面拼合：复制粘贴，100% 一致；特殊线条 → 等长的线 → 拆分选项。**
